## What I Do

UI and UX matter.  
They take taste, clarity, and attention to detail.

But what really determines whether a product works is structure.

Roles. Permissions. Data flows.  
Failure states. Edge cases. Scaling.

That’s the layer most people don’t see.  
That’s the layer I build.

Good design on the surface.  
Solid architecture underneath.

---

## Approach

- Clarify the product before writing code  
- Design structure first (data models, roles, workflows)  
- Build in small, shippable milestones  
- Ensure long-term maintainability
